
# invostar

## Application name

This application will be called as **INVOSTAR**

## Theme & Color

The application should follow the monochrome theme as below.

- Border Radius should be 0 always
- Transitions should be smooth
- Dark, Light & System theme should be supported
- Colors used in the application should be **Neutral colors palette** from **Tailwind CSS** and must follow the naming convention of semantic colors like `.bg-card`, `.dark:bg-card`, `.bg-primary`, `.dark:bg-primary`, etc.

## Font

Use the following fonts only.

- Geist
- Geist Mono
