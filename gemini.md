# Invostar

This is a billing and inventory management system for any business which are related to selling product or goods. This helps them to manage their inventory and sales and also provide analytics about their business. Also it helps to manage the customers and their purchase history. The project will be module based & can be delivered to most of the buisness easily without changing much code. The system will be highly configurable, allowing businesses to customize it to their specific needs. It will also be scalable, allowing it to be used by businesses of all sizes.
 
It has two main parts:

1. "Billing Backend", where all business logic, database connection and models. Framework to be used is nestjs & typescript.
2. "Billing frontend", where the UI for the application. Framework to be used is Next.js & Typescript. It uses shadcnui for UI components. It uses tailwindcss for styling.

## Guidelines

### For backend development

1. Always use nestjs for backend development
2. Always use typescript for backend development
3. Always use prisma for database connection and models
4. Always use pino-pretty for logging
5. Always use helmet for security
6. Always use compression for security

### For frontend development

1. Always follow the brand guidelines given in "./BRANDING.md" file.
2. Always use nextjs for frontend development
3. Always use typescript for frontend development
4. Always use shadcnui for UI components
5. Always use tailwindcss for styling
6. Always use zod for validation
7. Always use react-hook-form for forms 
8. Use tanstack-query + axios for fetching data & pagination
9. Use tanstack-table for tables
10. Use Skeleton effect for loading effects
